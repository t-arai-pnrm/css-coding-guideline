# ルールの定義

本書のルールは、このディレクトリの YAML ファイルだけで管理します。各ページの `<Guideline />`、付録A「ルール一覧」、AI 向けのルール集とスキル（`pnpm gen:ai`）は、すべてここから作ります。

- ファイルは章ごとに分けます（例: `13-responsive.yaml`）。ファイル名の順に読み込み、ファイルの中では書いた順に並びます。
- 各ファイルにはルールの配列を書きます。

```yaml
- id: query-range-syntax # 章の構成に依存しない英語のスラッグ。公開後は変えない
  level: 必須 # 必須 / 推奨 / 非推奨 / 禁止
  rule: メディアクエリとコンテナサイズクエリの条件は範囲構文で書く。 # 1文で書く
  reason: 条件の意味が式として読め、境界の値を含むかどうかも明確になるため。
  note: 補足や例外があれば書く。 # 省略可
  lint: 'Stylelint: `media-feature-range-notation`' # 自動チェックの手段。省略可
  aiProne: true # AI が誤りやすいもの。省略すると false
  page: responsive/media-queries # 掲載するページの ID
  since: 0.1.0 # 追加したバージョン
```

- ルール本文・理由・補足では、バッククォートで囲んだ部分がコードとして表示されます。
- ルールを変えたり消したりしたらメジャー、追加したらマイナーのバージョンを上げ、付録F「更新履歴」に書きます。
