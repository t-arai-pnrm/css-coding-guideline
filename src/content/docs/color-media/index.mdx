色は `oklch()` で定義し、派生させた色は元の色から関数で作ります。そのうえで、ブラウザやユーザーの設定によって色が置き換わる場面まで想定しておきます。画像と装飾も、比率やアイコンの色を指定するだけでは足りません。画像が表示されない場合や、強制カラーモードでも壊れない書き方を選びます。

色は見た目だけの問題に見えますが、アクセシビリティに直結します。強制カラーモードでは、`background-color` で描いたアイコンが消え、背景色だけで範囲を示していたボタンはただの文字になります。Windowsのユーザーの約4%が強制カラーモードを使っているというデータもあり、無視できる数ではありません。色の違いだけで伝えた情報は、色の見え方が違う人には伝わらないので、実装後にはグレースケールの表示でも確かめます。

色の書き方そのものも大きく変わりました。16進数で色を管理していた頃は、透過させた色のためにRGBの値を別のトークンとして持つ必要がありました。いまは、相対カラー構文と `color-mix()` で、元の色から派生させた色を作れます。ダークモードも `light-dark()` を使えば、トークンの側だけで切り替えられます。

この章は次の5つの節で構成しています。

- [11-1 色とダークモード](/color-media/color/)：`oklch()`、相対カラー構文、`color-mix()` で色を定義する方法と、`light-dark()` とメタ要素の `color-scheme` によるダークモードとテーマの切り替え
- [11-2 強制カラーモードとコントラスト](/color-media/forced-colors/)：システムカラー、透明な枠線、背景色で描いた図形のフォールバックと、グレースケールやコントラスト比による確認
- [11-3 画像と装飾](/color-media/images-and-decoration/)：`aspect-ratio` と `object-fit`、`srcset` と `sizes`、`clip-path` とマスク、`currentColor` のアイコン、影と角丸、文字の縁取り
- [11-4 角の形を変える](/color-media/shapes/)：`corner-shape` によるスクワークルや反り返るタブと、画面いっぱいのときだけ角丸を消す `sign()`
- [11-5 輪郭と枠線を描く](/color-media/outlines/)：`clip-path` の `shape()` によるタブと吹き出し、`border-shape`、`border-area` のグラデーションの枠線、マスクで描くドーナツグラフ

色の関数をスペースで区切る記法は[第6章「記法の規約」](/notation/)で、色のトークンをプリミティブとセマンティクスの2層で持つ設計は[第7章「コンポーネントとカスタムプロパティ」](/components/)で扱います。ダークモードに対応しないときの `color-scheme` の注意と、フォーカスリングは[第5章「リセットとベーススタイル」](/reset/)で、ホバーのときの色の変え方は[第12章「インタラクションとモーション」](/interaction/)で説明します。この章のコード例では `@layer` の記述を省略していますが、デモのCSSには省略せずに書いています。

## 最初に押さえるルール

{/* 要確認: 著者の優先順位で選び直す（レビューの提案にもとづく下書き） */}

次のルールを先に押さえ、ほかのルールは、該当する場面で付録A「[ルール一覧](/appendix/rules/)」から引けば足ります。

- [`text-contrast-aa`](/color-media/forced-colors/#rule-text-contrast-aa)：文字と背景のコントラスト比は、WCAG 2.1のAAを満たします。
- [`no-color-only-information`](/color-media/forced-colors/#rule-no-color-only-information)：本文の中のリンク、フォーカスやホバーの状態、入力エラーを、色の違いだけで伝えません。
- [`transparent-border-over-none`](/color-media/forced-colors/#rule-transparent-border-over-none)：枠線を消すときは、`border: none` ではなく `border-color: transparent` で透明にします。
- [`img-width-height-attributes`](/color-media/images-and-decoration/#rule-img-width-height-attributes)：`<img>` には、画像の実際の大きさを `width` と `height` の属性で書きます。
- [`no-lazy-loading-first-view`](/color-media/images-and-decoration/#rule-no-lazy-loading-first-view)：ファーストビューで表示される画像には、`loading="lazy"` を指定しません。
