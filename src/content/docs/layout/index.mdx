この章では、要素を並べる、間を空ける、重ねるといったレイアウトの書き方を扱います。レイアウトは、まず親の `grid-template` で配置と余白を決められないかを考え、子要素の側には配置のための指定をなるべく書きません。そのうえで、内容の長さや量が変わっても崩れないように、守りの指定を加えます。

私が勧めているのは、FlexboxではなくGridから考え始めることです。「1次元ならFlexbox、2次元ならGrid」という分け方が広まっていますが、1行の並びでもGridのほうが簡潔に書ける場面は多くあります。何でもFlexboxで組むと、子要素の側に幅の計算や打ち消しの指定が散らばり、レイアウトの全体像がどこにも書かれていない状態になりがちです。

もうひとつ大事にしているのは、内容が変わっても崩れないことです。一般的なWebサイトは公開後も更新が続き、とくにCMSの案件では、デザインカンプにない長さの見出しや、画像のない記事が入ってきます。既存のサイトの改修では、長いURLや入力欄が枠を突き抜ける不具合を直す作業が、定期的に発生します。こうした不具合の多くは、書くときに「もし〜だったら」と考えておけば防げるという印象です。

この章は次の13の節で構成しています。7-1〜7-5は、ほかの節が前提にしている仕組みの基礎です。

- [7-1 レイアウトの基礎](/layout/fundamentals/)：通常フローの2つの方向、`display` の外側と内側、包含ブロック、インラインの行とベースライン、配置の方式、FlexboxとGridの配置のプロパティ
- [7-2 ボックスモデルの基礎](/layout/box-model/)：内容・`padding`・`border`・`margin` の領域、`box-sizing`、大きさの決まり方と `%` の基準
- [7-3 マージンの相殺](/layout/margin-collapse/)：相殺が起きる条件と起きない条件、負のマージンを含む計算、相殺の止め方
- [7-4 Flexboxの基礎](/layout/flexbox-basics/)：主軸と交差軸、`flex-grow`・`flex-shrink`・`flex-basis` による空間の配り方、折り返し
- [7-5 Gridの基礎](/layout/grid-basics/)：トラック・線・エリアの用語、明示的なグリッドと暗黙のグリッド、配置のプロパティ
- [7-6 Gridから考える](/layout/grid-first/)：FlexboxとGridの使い分け、`grid-template` のエリア、サブグリッドでそろえるカード
- [7-7 余白を設計する](/layout/spacing/)：`gap` と `margin` の使い分け、空のグリッドセルで作る余白、本文の流れの余白
- [7-8 変化に強いレイアウト](/layout/defensive/)：内容の長さや量が変わっても崩れない書き方（ディフェンシブCSS）
- [7-9 重なりと配置](/layout/positioning/)：包含ブロック、スタッキングコンテキスト、アンカーポジショニング、画面幅いっぱいに広げる手法
- [7-10 ページのスクロールとルートスクローラー](/layout/root-scroller/)：ページ全体のスクロールを入れ子のスクロールコンテナにしてしまう原因と、用途ごとの直し方
- [7-11 sticky が動かないとき](/layout/sticky/)：`position: sticky` を妨げる4つの原因と直し方
- [7-12 grid-lanesで石積みのレイアウトを組む](/layout/masonry/)：高さの違う項目を詰める `display: block grid-lanes`、未対応の環境へのフォールバック、`columns` との使い分け
- [7-13 コンポジション集](/layout/compositions/)：stack、cluster、switcher、gridなど、配置のパターンを部品にしたコンポジションの使い方と使い分け（7-13-1〜7-13-11）

コンポーネントのルートに外側の余白を持たせない考え方と、z-indexの管理は[第6章「コンポーネントとカスタムプロパティ」](/components/)で扱います。幅に応じてレイアウトを切り替える方法は[第8章「レスポンシブデザイン」](/responsive/)で、フレックスアイテムとグリッドアイテムの最小幅を0にするベーススタイルは[第4章「リセットとベーススタイル」](/reset/)で説明しています。

この章のコード例では、説明に関係しない `@layer` の記述を省略しています。デモのCSSには省略せずに書いています。
