この章では、要素の大きさと位置がどう決まるのかという、レイアウトの仕組みを扱います。CSSのレイアウトは、通常フロー、Flexbox、Grid、位置指定（`position`）という複数の方式でできていて、同じ `margin` や `inline-size` でも、要素がどの方式の中にあるかで働き方が変わります。この章は、その規則を方式ごとに整理し直すための章です。

レイアウトの不具合の多くは、方式の規則を知らないまま値を足したことから生まれます。インライン要素に上下の余白を付けても空かない、`position: sticky` が留まらない、フレックスアイテムが縮まずにはみ出す、といった場面は、どれも方式の規則どおりの振る舞いです。値を少しずつ変えて見た目を合わせる前に、要素がどの方式の中にあり、何を基準に大きさが決まっているのかを確かめます。CSSをレイアウトのアルゴリズムの集まりとして捉える考え方は、「[1-3 CSSはレイアウトのアルゴリズムの集まりである](/principles/layout-algorithms/)」で説明しています。

この章は次の12の節で構成しています。7-1で方式の全体像を示し、7-2〜7-10で方式ごとの規則を説明します。7-11と7-12では、位置指定を広げるアンカーポジショニングと、箱をなくす `display: contents` を扱います。

- [7-1 レイアウトの基礎](/layout/fundamentals/)：レイアウトの方式の全体像、方式を決める親の `display`、同じ幅の指定が方式ごとに違う意味を持つこと、包含ブロックの要約、重なり、FlexboxとGridの配置のプロパティ、効かない指定を調べる順番
- [7-2 通常フローの基礎](/layout/normal-flow/)：ブロック方向とインライン方向、ブロックとインラインのボックス、行ボックスと匿名ボックス、幅と高さの決まり方、`display: flow-root`
- [7-3 ボックスモデルの基礎](/layout/box-model/)：内容・`padding`・`border`・`margin` の領域、`box-sizing`、`margin` の負の値と `auto`、大きさに含まれない `outline` と `box-shadow`
- [7-4 大きさの決まり方](/layout/sizing/)：`auto` と中身に合わせた大きさ、`min-inline-size` と `max-inline-size` による下限と上限、`%` の基準、幅いっぱいに広げる `stretch`
- [7-5 marginの役割](/layout/margin-role/)：縦に長い文書のための `margin`、`margin`・`padding`・`gap` が受け持つ余白の違い、レイアウトの間隔と文章の要素の間の余白の書き分け
- [7-6 マージンの相殺](/layout/margin-collapse/)：相殺が起きる条件と起きない条件、負のマージンを含む計算、`display: flow-root` による相殺の止め方
- [7-7 Flexboxの基礎](/layout/flexbox-basics/)：主軸と交差軸、`flex-grow`・`flex-shrink`・`flex-basis` による空間の配り方、折り返し
- [7-8 Gridの基礎](/layout/grid-basics/)：トラック・線・エリアの用語、`fr`・`fit-content()`・`minmax()` によるトラックの大きさ、明示的なグリッドと暗黙のグリッド、`grid-template` のエリア、アイテムの最小幅
- [7-9 Gridでアイテムをそろえる](/layout/grid-alignment/)：`*-items` と `*-content` の違い、サブグリッドでそろえるカードの行と一覧の列、画像の幅に合わせて決める列
- [7-10 positionの基礎](/layout/positioning/)：`position` の5つの値、包含ブロック、絶対配置の要素を中央に置く方法、`sticky` が留まらない原因
- [7-11 アンカーポジショニングの基礎](/layout/anchor-basics/)：`anchor-name` と暗黙のアンカー、`anchor()`、`position-area` の9マス、`position-try-fallbacks` による反転、未対応の環境への備え
- [7-12 display: contentsで箱をなくす](/layout/display-contents/)：箱だけをなくす仕組み、幅で並びを変えるだけならエリアで組む理由、サブグリッドへの参加とラッパーの箱の出し入れ、ロールと `hidden` 属性の注意点

これらの仕組みを使って、作るものに合わせて手法を選び、余白を設計し、内容が変わっても崩れないように組む方法は、第11章「[レイアウトを組む](/layout-practice/)」で扱います。`position` を応用する固定ヘッダーは「[11-7 固定ヘッダー](/layout-practice/sticky-header/)」で、アンカーポジショニングは「[11-8 アンカーポジショニング](/layout-practice/anchor-positioning/)」で説明しています。配置のパターンを部品にしたコンポジションは第12章「[レイアウトコンポジション](/compositions/)」で、フレックスアイテムとグリッドアイテムの最小幅を0にするベーススタイルは第8章「[リセットとベーススタイル](/reset/)」で説明しています。

この章のコード例では、説明に関係しない `@layer` の記述を省略しています。デモのCSSには省略せずに書いています。

## 初めて読むとき

初めて読むときは、「[7-1 レイアウトの基礎](/layout/fundamentals/)」「[7-2 通常フローの基礎](/layout/normal-flow/)」「[7-3 ボックスモデルの基礎](/layout/box-model/)」「[7-4 大きさの決まり方](/layout/sizing/)」「[7-5 marginの役割](/layout/margin-role/)」「[7-7 Flexboxの基礎](/layout/flexbox-basics/)」「[7-8 Gridの基礎](/layout/grid-basics/)」を読みます。7-6のマージンの相殺は、余白の大きさが予想と違うときに読んでください。7-9以降のGridのそろえ方、`position`、アンカーポジショニング、`display: contents` は、その仕組みを使うときに読みます。

## 最初に押さえるルール

次のルールを先に押さえ、ほかのルールは、該当する場面で付録A「[ルール一覧](/appendix/rules/)」から引けば足ります。

- [`identify-layout-mode-first`](/layout/fundamentals/#rule-identify-layout-mode-first)：配置が思いどおりにならないときは、値を足す前に、その要素がどのレイアウトの方式の中にあるかを確かめます。
- [`flexbox-check-auto-min-size`](/layout/flexbox-basics/#rule-flexbox-check-auto-min-size)：フレックスアイテムが縮まずにはみ出すときは、固定の幅を足す前に、自動の最小幅を確かめます。
- [`sticky-align-self-start`](/layout/positioning/#rule-sticky-align-self-start)：GridやFlexboxの子に `position: sticky` を指定するときは、その要素に `align-self: start` も指定します。
- [`flexbox-no-visual-reorder`](/layout/flexbox-basics/#rule-flexbox-no-visual-reorder)：フォーカスできる要素や順番に意味のある要素を、`order` や `row-reverse` で見た目だけ入れ替えません。

## この章で判断できるようになること

この章を読むと、配置が思いどおりにならないとき、値を足す前に、要素がどの方式の中にあり、大きさが何で決まっているかから原因を特定できるようになります。フレックスアイテムがはみ出すなら自動の最小幅を、GridやFlexboxの子で `position: sticky` が留まらないなら `align-self` を確かめる、というように、症状に合った規則から調べられます。余白を `margin`、`padding`、`gap` のどれに受け持たせるか、マージンの相殺が起きる条件にあるか、`display: contents` で箱をなくしてよいかも判断できます。
