コンポーネントは、自分以外のことを何も参照しない状態で書きます。自分がどこに置かれ、周りに何があるかで決まるスタイルは、コンポーネントの外側に任せます。この章では、この考え方にもとづくコンポーネントどうしの境界の引き方と、カスタムプロパティによる値の受け渡しを扱います。

私がコンポーネントを書くうえで目標としているのは、関係のない場所（たとえばフッター）へそのまま移しても崩れないことです。ルートに外側の余白を持たせたり、親から子の内部をセレクタで書き換えたりすると、この目標はすぐに崩れます。親のCSSは子の内部構造に、子のCSSは親の置き方に依存するので、片方を直すともう片方も直すことになり、やがて詳細度の上書き合戦が始まります。

境界を守ったまま値をやり取りする手段が、カスタムプロパティです。子のコンポーネントは「外から変えてよい値」だけを公開プロパティとして用意し、親はその値を渡すだけにします。サイト全体で共有する値はデザイントークンにまとめ、別のコンポーネントの間で見た目をそろえたいときも、コンポーネントを統合せずにトークンを参照します。この考え方は、新しく作るサイトだけでなく、詳細度が破綻した既存のCSSを改修するときにも役立ちます。

章は次の4つの節で構成しています。各コンポジションの詳しい使い方は、「[8-13 コンポジション集](/layout/compositions/)」で説明しています。

- [7-1 コンポーネントの境界を守る](/components/boundaries/)：1つのコンポーネントを1つのファイルに書くこと、外部関連型のレイアウトをルートへ書かない理由、ほかのコンポーネントの内部を触らずに値を渡す方法、z-indexの扱い
- [7-2 コンポジションとユーティリティ](/components/compositions-and-utilities/)：stackやclusterなどの配置のパターンと、ユーティリティにする範囲
- [7-3 デザイントークン](/components/design-tokens/)：`--<分類>--<名前>` の命名と、余白・色・イージング・z-indexのトークンの設計
- [7-4 公開プロパティと内部プロパティ](/components/custom-properties/)：カスタムプロパティの命名、状態を表す接尾辞、`style` 属性での受け渡し、`@property` の使いどころ

コード例で使っている `@scope (.scoped.<名前>) to (.scoped)` の仕組みは「[2-4 @scopeでスタイルを閉じ込める](/cascade/scope/)」で、レイヤーの順序は「[2-3 カスケードレイヤーで順位を決める](/cascade/layers/)」で説明しています。クラス名の付け方は「[6-1 命名規則](/notation/naming/)」で扱います。`gap` と `margin` の使い分けは「[8-7 余白を設計する](/layout/spacing/)」で、スタッキングコンテキストの仕組みは「[8-9 重なりと配置](/layout/positioning/)」で扱います。この章のコード例では、説明に関係しない `@layer` の記述を省略しています。デモのCSSには省略せずに書いています。

## 最初に押さえるルール

{/* 要確認: 著者の優先順位で選び直す（レビューの提案にもとづく下書き） */}

次のルールを先に押さえ、ほかのルールは、該当する場面で付録A「[ルール一覧](/appendix/rules/)」から引けば足ります。

- [`no-other-component-internals`](/components/boundaries/#rule-no-other-component-internals)：ほかのコンポーネントのルートや内部の要素を、セレクタで選んで見た目を上書きしません。
- [`one-component-per-file`](/components/boundaries/#rule-one-component-per-file)：コンポーネントのCSSは、コンポーネントごとに1つのファイルに書きます。
- [`public-property-naming`](/components/custom-properties/#rule-public-property-naming)：外から変えてよい値は、`--card--radius` のような `--<コンポーネント>--<プロパティ>` の公開プロパティにします。
- [`receive-public-property-with-fallback`](/components/custom-properties/#rule-receive-public-property-with-fallback)：公開プロパティはコンポーネント自身では宣言せず、`:scope` で内部プロパティに受けて、デフォルト値を `var()` のフォールバックに書きます。
- [`z-index-tokens-only`](/components/boundaries/#rule-z-index-tokens-only)：z-indexの値は、数値を直接書かずにトークンで指定します。
