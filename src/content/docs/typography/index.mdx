文字の組版は、ブラウザとユーザーの設定に任せる範囲を広く取り、見出しのように目立つ場所だけを整えます。フォントは総称ファミリーの `sans-serif` に任せ、本文は文字を詰めないベタ組みにし、行の高さは1.5以上を保ちます。

ブラウザのデフォルトスタイルや、海外で作られたリセットCSSの多くは、欧文の組版を前提にしています。日本語のサイトでは、和文と英数字の間のアキ、約物の詰め、厳格な禁則といった和文向けの指定を、自分で足す必要があります。反対に、欧文の感覚で文字を詰めたり行の高さを削ったりすると、和文は読みにくくなります。

私自身、2020年の記事では、OSごとのフォントを長く並べ、本文全体に `palt` で文字を詰める書き方を勧めていました。その後、WindowsにNoto Sans JPが標準で入り、CSSにも `text-autospace` や `text-box-trim` のような組版のためのプロパティが増えました。いまは、CSSで細かく作り込むよりも、ブラウザの機能に任せて読みやすさを保つほうが、保守しやすく壊れにくいと考えています。

本書のサイトも、この章の考え方で作っています。原稿には和文と英数字の間に空白を入れず、フォントは `sans-serif` だけを指定し、見出しだけを `palt` で詰めて、対応するブラウザでは文節で折り返しています。

この章は次の4つの節で構成しています。

- [10-1 フォントを指定する](/typography/fonts/)：総称ファミリーに任せる理由、端末のフォントを優先する `@font-face`、Webフォントの読み込み方、和文で斜体を使わない理由
- [10-2 和文組版を整える](/typography/japanese-typesetting/)：`text-autospace`、`text-spacing-trim`、`line-break` の値の選び方と、本文のベタ組みと見出しの詰め
- [10-3 行の高さとハーフレディング](/typography/line-height/)：ベースの行の高さ、`line-height: 1` を使わない理由と、ハーフレディングを取り除く方法
- [10-4 文字サイズと改行](/typography/size-and-line-breaks/)：流体的な文字サイズのユーティリティ、見出しを文節で折り返す方法、手動の改行と行数の制限

単位のない `line-height` と `clamp()` の組み立て方は第4章「[値と単位](/values/)」で、kiso.cssが入れている和文向けの初期値は第5章「[リセットとベーススタイル](/reset/)」で扱います。行の高さや文字の太さのトークンは第7章「[コンポーネントとカスタムプロパティ](/components/)」で、文字を含む要素のアニメーションは第13章「[インタラクションとモーション](/interaction/)」で扱います。この章のコード例では、説明に関係しない `@layer` の記述を省略しています。デモのCSSには省略せずに書いています。

## 最初に押さえるルール

{/* 要確認: 著者の優先順位で選び直す（レビューの提案にもとづく下書き） */}

次のルールを先に押さえ、ほかのルールは、該当する場面で付録A「[ルール一覧](/appendix/rules/)」から引けば足ります。

- [`base-line-height-min`](/typography/line-height/#rule-base-line-height-min)：ベースの `line-height` は1.5以上にして、各要素に継承させます。
- [`no-line-height-one`](/typography/line-height/#rule-no-line-height-one)：`line-height: 1` を指定しません。
- [`lang-for-typesetting`](/typography/japanese-typesetting/#rule-lang-for-typesetting)：`html` 要素とほかの言語で書いた部分に `lang` 属性を付け、言語ごとの組版を `:lang()` で切り替えます。
- [`overflow-wrap-over-word-break`](/typography/size-and-line-breaks/#rule-overflow-wrap-over-word-break)：`word-break` は初期値のままにし、長い単語やURLのはみ出しは `overflow-wrap: anywhere` で防ぎます。
