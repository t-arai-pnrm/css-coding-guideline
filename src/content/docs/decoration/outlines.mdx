要素の輪郭は `clip-path` の `shape()` で、枠線の塗りは `background-clip: border-area` で描きます。どちらも、以前は複数の擬似要素やマスクの重ね合わせで作っていた形を、1つか2つの宣言で書けるようにする機能です。`shape()` はすべての主要なブラウザが対応していますが、`border-area` は対応が分かれています。

`border-area` は、未対応の環境で宣言全体が無効になり、何も描かれなくなることがあります。そのため、未対応の環境での見え方を先に確かめ、`@supports` で従来の書き方に切り替えます。角の形だけを変える `corner-shape` は「[16-4 角の形を変える](/decoration/shapes/)」で扱います。`polygon()` で図形を切り抜く書き方と、`mask-image` の基本は「[16-2 アイコン・SVG・マスク](/decoration/icons-and-masks/)」で説明しています。

## 輪郭を描く方法の違い

三角の尻尾が付いた吹き出し、下の端が反り返るタブ、グラデーションで塗った枠線は、`border-radius` だけでは作れません。これまでは、擬似要素を重ねたり、`mask-composite: exclude` で内側をくり抜いたりして作ってきました。形を作るための要素と、半径から逆算した位置の値が増え、コードから形を読み取れなくなります。

`shape()` は、輪郭そのものを直線と曲線の命令で描きます。`border-area` は、背景を枠線の部分だけに切り抜くので、枠線をグラデーションや円グラフで塗れます。どちらも、形を作るための余分な要素が要らず、形を決める値がカスタムプロパティから計算できるので、コードから形を読み取れます。

## clip-path の shape() で輪郭を描く

`shape()` は、`clip-path` などで使う図形の関数です。`polygon()` は頂点を直線でつなぐことしかできず、`path()` はSVGのパスの文字列なので、`%` や `calc()`、カスタムプロパティが使えませんでした。`shape()` は、直線と曲線の命令をCSSの値で書けるので、要素の大きさに合わせて伸び縮みする輪郭を描けます。

次の例は、「[16-4 角の形を変える](/decoration/shapes/)」で `corner-shape: scoop` を使って作った、下の端が反り返るタブを、`shape()` で描いたものです。`shape()` はすべての主要なブラウザが対応しているので、`corner-shape` に対応していない環境でも反り返りが付きます。

```css title="🙆‍♂ Recommended: 反り返るタブを、擬似要素1つの shape() で描く"
@scope (.scoped.tab-list) to (.scoped) {
  ._tab {
    --_radius: var(--tab-list--radius, 12px);

    position: relative;
    padding-block: 8px;
    padding-inline: 24px;
    isolation: isolate;

    &::before {
      content: "";
      position: absolute;
      inset-block: 0;
      inset-inline: calc(var(--_radius) * -1);
      z-index: var(--z--backwards);
      clip-path: shape(
        from 0 100%,
        curve to var(--_radius) calc(100% - var(--_radius)) with var(--_radius) 100%,
        vline to var(--_radius),
        curve to calc(var(--_radius) * 2) 0 with var(--_radius) 0,
        hline to calc(100% - var(--_radius) * 2),
        curve to calc(100% - var(--_radius)) var(--_radius) with calc(100% - var(--_radius)) 0,
        vline to calc(100% - var(--_radius)),
        curve to 100% 100% with calc(100% - var(--_radius)) 100%,
        close
      );
      background-color: var(--background--base);

      @supports not (clip-path: shape(from 0 0, hline to 0)) {
        inset-inline: 0;
        border-start-start-radius: var(--_radius);
        border-start-end-radius: var(--_radius);
      }
    }
  }
}
```

<Demo title="選んでいるタブの輪郭を、shape() で反り返らせて描く" html={shapeTabHtml} css={shapeTabCss} />

このデモでは、選んでいるタブにだけ背景色を付けるため、擬似要素の背景色を `--_background` から受け取っています。選んでいないタブでは透明なので、輪郭は描かれていても見えません。

擬似要素をタブより左右に半径の分だけ広げ、その輪郭を `shape()` で切り抜いています。左下から始めて、外側へ反った曲線、左上の角丸、上の辺、右上の角丸、右下の反った曲線の順に、輪郭を一周します。`curve to 終点 with 制御点` は2次ベジェ曲線なので、正確な四分円ではありませんが、この大きさの角では見分けがつきません。{/* 要確認: 出典なし */}

`shape()` の値は長く、そのままでは何を描いているのか読み取れません。そこで、半径を `--_radius` に入れ、すべての座標をその半径から計算します。角の大きさを変えるときは、公開用の `--tab-list--radius` を変えるだけで済み、座標を書き直す必要がありません。輪郭の高さは半径の2倍以上必要なので、タブの高さに対して半径を大きくしすぎないようにします。

`shape()` は、2026年2月にすべての主要なブラウザで使えるようになりました。Safariは18.4から対応しているので、本書の対象（Safari 18系の最終版以降）では使えます。それより古い環境で `clip-path` が無効になると、背面の擬似要素が切り抜かれずに左右へはみ出すので、`@supports not` の中で幅を戻し、上だけを `border-radius` で丸めます（2026年10月確認）。

### 吹き出しの枠線と border-shape

吹き出しも、本体としっぽを1つの `shape()` で描けば、擬似要素を使わずに作れます。ただし、`clip-path` は要素の描画を切り抜くだけなので、ふつうの `border` を付けると、しっぽの部分と下の辺の枠線が切り落とされます（2026年10月、Chrome 152で確認）。枠線を輪郭に沿わせるには、要素の枠線そのものを図形の関数で指定する `border-shape` を使います。`border-shape` に対応しているのはChrome 147以降だけなので、輪郭は `clip-path` で描き、枠線だけを `@supports` で足します（2026年10月確認）。

```css title="🙆‍♂ Recommended: 輪郭を1つのカスタムプロパティにして、clip-path と border-shape で共有する"
@scope (.scoped.balloon) to (.scoped) {
  :scope {
    --_padding-block: var(--balloon--padding-block, 24px);
    --_radius: var(--balloon--radius, 12px);
    --_arrow-half-width: calc(var(--balloon--arrow-width, 24px) / 2);
    --_arrow-height: calc(var(--_arrow-half-width) * tan(60deg)); /* 正三角形の高さ */
    --_arrow-position: var(--balloon--arrow-position, 50%);
    --_shape: shape(
      from var(--_radius) 0,
      hline to calc(100% - var(--_radius)),
      curve to right var(--_radius) with right top,
      vline to calc(100% - (var(--_radius) + var(--_arrow-height))),
      curve to calc(100% - var(--_radius)) calc(100% - var(--_arrow-height)) with right calc(100% - var(--_arrow-height)),
      hline to calc(var(--_arrow-position) + var(--_arrow-half-width)),
      line by calc(var(--_arrow-half-width) * -1) var(--_arrow-height),
      line by calc(var(--_arrow-half-width) * -1) calc(var(--_arrow-height) * -1),
      hline to var(--_radius),
      curve to left calc(100% - (var(--_radius) + var(--_arrow-height))) with left calc(100% - var(--_arrow-height)),
      vline to var(--_radius),
      curve to var(--_radius) top with left top,
      close
    );

    clip-path: var(--_shape);
    padding-block: var(--_padding-block) calc(var(--_padding-block) + var(--_arrow-height));
    padding-inline: 24px;
    background-color: var(--background--base);

    @supports (border-shape: shape(from 0 0, hline to 0)) {
      border: 4px solid var(--color--accent--300);
      border-shape: var(--_shape);
    }
  }
}
```

<Demo title="Chrome 147以降では枠線が輪郭に沿い、未対応の環境では塗りだけの吹き出しになる" html={balloonHtml} css={balloonCss} />

輪郭は、左上の角丸の終わりから時計回りに一周します。右下の角丸のあと、しっぽの右端まで下の辺を戻り、`line by` でしっぽの先端へ下りてから、しっぽの左端へ上がります。しっぽの位置 `--_arrow-position` は、しっぽの中心を本体の左端からの距離で指定します。`shape()` の値は、`--_shape` という1つのカスタムプロパティに入れ、`clip-path` と `border-shape` の両方から参照します。同じ輪郭を2か所に書くと、片方だけを直したときに、枠線と塗りの形がずれるからです。

しっぽは正三角形にしています。高さは、幅の半分に `tan(60deg)` を掛けた値です。正三角形の底辺の半分と高さは、60度の角をはさむ直角三角形の2辺なので、この比になります。しっぽは本体の下の `padding` の中に描くので、下の `padding` には、しっぽの高さを足します。足さないと、本体の下の辺が `padding` の内側へ上がり、本文の下の余白が、しっぽの高さの分だけ狭くなります。

`border-shape` に対応した環境では、枠線と背景が `border-shape` の輪郭に沿って描かれます（2026年10月、Chrome 152で確認）。`clip-path` を外しても見た目はほぼ変わりませんが、未対応の環境で形を作るのは `clip-path` なので、両方を書きます。未対応の環境では、`@supports` の中の `border` も使われないので、枠線のない塗りだけの吹き出しになります。`border` を `@supports` の外に書くと、しっぽと下の辺の枠線だけが切り落とされた、欠けた枠になります。

## background-clip: border-area でボーダーを塗る

`background-clip: border-area` は、背景を枠線が描かれる部分だけに切り抜く値です。枠線の色を `transparent` にし、背景のグラデーションを `border-area` で切り抜けば、グラデーションの枠線になります。擬似要素とマスクは要りません。

```css title="🙆‍♂ Recommended: 対応している環境だけ、枠線をグラデーションにする"
@scope (.scoped.feature-card) to (.scoped) {
  :scope {
    padding: 24px;
    border: 2px solid var(--color--accent--500);
    border-radius: var(--rounded--lg);
    background-color: var(--background--base);

    @supports (background-clip: border-area) {
      border-color: transparent;
      background:
        linear-gradient(in oklch 90deg, var(--color--accent--500), var(--color--accent--700)) border-area,
        var(--background--base);
    }
  }
}
```

<Demo title="対応している環境では、枠線がグラデーションになる" html={gradientBorderHtml} css={gradientBorderCss} />

`border-color: transparent` は、`@supports` の中に書きます。外に書くと、未対応の環境では背景の切り抜きが効かないまま枠線だけが透明になり、枠線が消えるからです。`@supports` で分けておけば、未対応の環境では単色の枠線として表示されます。グラデーションの枠線は装飾なので、多くの場合は単色の枠線で足ります。

`border-area` は、Safari 18.2以降とChrome 150以降が対応しています。Firefoxは未対応です（2026年10月確認）。

### どの環境でもグラデーションの枠線にする

ブランドの表現として、Firefoxでもグラデーションの枠線を見せる必要があるなら、擬似要素にグラデーションを敷き、内側をマスクでくり抜きます。マスクの合成（`mask-composite`）は、本書の対象のブラウザのすべてが対応しています。ただし、擬似要素とマスクの指定が増え、`border-area` の2つの宣言に比べて、何を描いているのかがコードから読み取りにくくなります。単色の枠線で足りる場面では、前の例の `border-area` を使います。

```css title="🙆‍♂ Recommended: 擬似要素の透明な枠線にグラデーションを敷き、内側をマスクでくり抜く"
@scope (.scoped.gradient-frame) to (.scoped) {
  :scope {
    --_border-width: var(--gradient-frame--border-width, 2px);
    --_radius: var(--gradient-frame--radius, var(--rounded--lg));
    --_gradient: var(
      --gradient-frame--gradient,
      linear-gradient(in oklch 90deg, var(--color--accent--500), var(--color--accent--700))
    );

    position: relative;
    padding: calc(24px + var(--_border-width));
    border-radius: var(--_radius);
    background-color: var(--background--base);
    isolation: isolate;

    &::before {
      content: "";
      position: absolute;
      inset: 0;
      z-index: var(--z--backwards);
      mask-image: conic-gradient(#000 0 0), conic-gradient(#000 0 0);
      mask-clip: padding-box, border-box;
      mask-composite: exclude;
      border: var(--_border-width) solid transparent;
      border-radius: var(--_radius);
      background-image: var(--_gradient);
      background-origin: border-box;
    }
  }
}
```

<Demo title="擬似要素とマスクで、どの環境でもグラデーションの枠線を描く" html={gradientBorderMaskHtml} css={gradientBorderMaskCss} />

枠線を描くのは `::before` です。`inset: 0` でルートと同じ大きさに広げ、透明な枠線を付けて、`background-origin: border-box` で枠線の外側からグラデーションを敷きます。`mask-image` には2枚の単色の画像を指定し、`mask-clip` で1枚目を `padding-box`、2枚目を `border-box` に切り抜きます。2枚を `mask-composite: exclude` で合成すると、2枚の重なる内側が消え、枠線の部分だけが残ります。`conic-gradient(#000 0 0)` は単色の画像を短く書くための指定です。マスクに使われるのは画像の不透明度だけなので、`#000` の色は表示されません（「[16-2 アイコン・SVG・マスク](/decoration/icons-and-masks/)」）。

擬似要素の枠線は、ルートの外周に重なって描かれます。ルート自身には枠線がないので、そのままでは中身が枠線の上に重なります。そこで、ルートの `padding` に枠線の太さを足しています。角丸の半径は、ルートと擬似要素の両方に同じ `--_radius` を指定します。ルートの背景色が擬似要素の角からはみ出さず、擬似要素の内側の角も、枠線の太さの分だけ小さな半径で丸まります。

擬似要素は `z-index: var(--z--backwards)` でルートの中身の背面に回し、ルートには `position: relative` と `isolation: isolate` を指定します。`isolation` でスタッキングコンテキストを作らないと、擬似要素はルートの背景よりも後ろに回り、ルートの背景色に隠れます（「[10-2 コンポーネントの境界を守る](/components/boundaries/#rule-isolation-for-relative-z-index)」）。

この書き方は、私のCodePen（Gradient Border）で使っているものです。CodePenでは、`position: relative` と `isolation` の代わりに `contain: content` を指定しています。`contain: content` に含まれるレイアウトの封じ込めは、要素を絶対配置の包含ブロックにし、スタッキングコンテキストも作るので、1つの宣言で同じ役割を果たします。ただし、ペイントの封じ込めも含むので、ルートからはみ出した子孫の影やポップアップが切り取られます（「[18-7 動きの負荷を抑える](/motion/performance/)」）。本書では、役割がそのまま読み取れる `position: relative` と `isolation: isolate` で書きます。

### ドーナツグラフ

ドーナツグラフは、`border-area` ではなく、擬似要素の内側をマスクでくり抜いて描きます。グラデーションの枠線は装飾なので単色に縮退させれば済みますが、グラフは割合という情報を表しているので、環境によって形を変えるわけにはいかないからです。`border-area` で描くと、未対応のFirefoxでは中心まで塗った円グラフになり、中心に置いた数値が塗りの上に重なります。マスクの合成（`mask-composite`）なら、本書の対象のブラウザのすべてで同じドーナツの形になります。

```css title="🙆‍♂ Recommended: マスクで輪を作り、割合を中心に数値でも示す"
@property --count-up--value {
  syntax: "<percentage>";
  inherits: false;
  initial-value: 0%;
}

@keyframes --count-up {
  from {
    --count-up--value: 0%;
  }
}

@scope (.scoped.donut-chart) to (.scoped) {
  :scope {
    --_value: min(var(--donut-chart--value, 0%), 100%);
    --_basis-width: 200px;
    --_border-width: 16px;
    --_foreground: var(--donut-chart--foreground, var(--color--accent--500));

    container: --scoped / inline-size;
    display: block grid;
    aspect-ratio: 1;
    color: var(--_foreground);

    &::before,
    &::after {
      --count-up--value: var(--_value);

      content: "";
      grid-area: 1 / 1;

      @media (prefers-reduced-motion: no-preference) {
        animation-name: --count-up;
        animation-duration: 1s;
        animation-timing-function: linear;
        animation-fill-mode: both;
      }
    }

    &::before {
      mask-image: conic-gradient(#000 0 0), conic-gradient(#000 0 0);
      mask-clip: padding-box, border-box;
      mask-composite: exclude;
      border: var(--_border-width) solid transparent;
      border-radius: calc(infinity * 1px);
      forced-color-adjust: none; /* 強制カラーモードでもグラデーションを画像として表示する */
      background-image: conic-gradient(currentColor var(--count-up--value), var(--color--neutral--200) 0);
      background-origin: border-box;
    }

    &::after {
      content: counter(--value) "%" / "";
      place-self: center;
      padding: var(--_border-width);
      counter-reset: --value calc(var(--count-up--value) / 1%);
      font-size: calc(32px / var(--_basis-width) * 100cqi);
      font-weight: 700;
      font-variant-numeric: tabular-nums;
    }
  }
}
```

値は、HTMLの `style` 属性で `--donut-chart--value: 40%` のように渡します。割合の数値そのものは、HTMLにも書きます。

```html title="割合をHTMLに書き、CSSには描画用の値を渡す"
<div class="scoped donut-chart" style="--donut-chart--value: 40%">
  <span class="-visually-hidden">40%</span>
</div>
```

<Demo title="割合に合わせて輪が伸び、中心の数値が数え上がるドーナツグラフ" html={donutHtml} css={donutCss} />

割合は、読み手が知る必要のある情報です。生成コンテンツだけで表示すると、コピーやページ内検索、機械翻訳の対象にならず、CSSが読み込まれない環境では数値が消えます（「[5-8 生成コンテンツと装飾の擬似要素](/pseudo/generated-content/#rule-no-meaningful-generated-content)」）。そこで、数値はHTMLの `span` に書いて `.-visually-hidden` で視覚的に隠し、中心で数え上げる `::after` の数値は、`content` の代替テキストを空にして装飾として扱います。読み上げではHTMLの「40%」だけが伝わり、数え上げの途中の値は読まれません。

`min()` で上限を100%にしているので、100%を超える値が渡っても、輪が1周を超えて塗られることはありません。グラフの色は `--donut-chart--foreground` で変えられ、輪と中心の数値が同じ色になります。

`::before` が輪です。前の例のグラデーションの枠線と同じく、透明な枠線を付け、`padding-box` と `border-box` に切り抜いた2枚のマスクを `exclude` で合成して、枠線の部分だけを残しています。そこに枠線の外側から（`background-origin: border-box`）`conic-gradient()` を敷くので、枠線の太さがそのまま輪の太さになります。

`::after` が中心の数値です。`calc(var(--count-up--value) / 1%)` は、割合を1%で割った単位のない数値を返し（「[6-3 計算関数で根拠を式に残す](/values/advanced-math-functions/#rule-typed-arithmetic-to-unitless)」）、`counter()` がその数値を文字にします。`counter-reset` は整数を受け取るので、`calc()` の結果は整数に丸められます。{/* 要確認: counter-reset に @property で登録した値の calc() を渡す書き方の対応状況 */}文字の大きさは、コンテナの幅（`100cqi`）に、グラフの幅が `--_basis-width`（200px）のとき32pxとなる比を掛けて決めています。グラフをどの大きさで置いても、輪と数値の大きさの比が変わりません。`tabular-nums` で数字の幅をそろえるのは、数値が増える間も文字の位置を左右に揺らさないためです。

割合は、0%から数え上げて表示します。`--count-up--value` は、`@property` で `<percentage>` の型を登録しています。型のないカスタムプロパティは、途中の値を補間できず、値が一瞬で切り替わります。`@keyframes` には `from` だけを書き、終わりの値は擬似要素で指定した値を使います（「[18-4 トランジションと@keyframes](/motion/transitions-and-keyframes/)」）。輪と数値は同じ `@keyframes` で動くので、輪が伸びるのに合わせて数値も増えます。トランジションではなく `@keyframes` を使うのは、トランジションは値が変わったときにしか動かず、ページを開いたときの表示では何も起きないからです。数値が一定の速さで増えるように、イージングは `linear` にしています。動かすのは、`prefers-reduced-motion: no-preference` のときだけです。

## 未対応の環境と強制カラーモードでの見え方

この節で扱った機能を使ったら、未対応の環境での見え方を、ブラウザを替えるか、開発者ツールで宣言を外して確かめます。`shape()` を使った `clip-path` は無効になると切り抜きがなくなるだけですが、`border-area` は宣言全体が無効になって何も描かれなくなるので、`@supports` がないと表示が崩れます。

`@supports` の条件には、実際に使う値の形を書きます。`@supports (background-clip: border-area)` のように値まで書くと、プロパティにだけ対応していて値に対応していない環境も、未対応として扱えます。`shape()` の条件は、`shape(from 0 0, hline to 0)` のように、構文として成り立つ最も短い形にしておくと読みやすくなります。

強制カラーモードでは、グラデーションの `background-image` が表示されなくなり、`border-color` はシステムカラーに置き換わります。そのため、`border-area` のグラデーションの枠線は、透明にした枠線がシステムカラーで描かれ、境界は残ります。擬似要素とマスクで描く枠線も、グラデーションは消えますが、擬似要素の透明な枠線がシステムカラーに置き換わり、マスクで残した枠線の形のまま描かれます。{/* 要確認: 擬似要素とマスクで描く枠線の強制カラーモードでの表示をブラウザで確認していない */}枠線は境界を示す装飾で、システムカラーの単色でも役割を果たすので、`forced-color-adjust: none` は指定しません。一方、何も指定しないとドーナツグラフはグラデーションごと消えてしまうので、輪の擬似要素にだけ `forced-color-adjust: none` を指定し、グラフを画像として表示させます。グラフは色の組み合わせで割合を表す図なので、システムカラーに置き換えると図として成り立たないからです。中心の数値には指定しないので、文字はユーザーの選んだ配色で表示されます。{/* 要確認: 強制カラーモードでの輪の表示をブラウザで確認していない */}強制カラーモードで置き換わる色の一覧は、「[15-5 強制カラーモードとコントラスト](/color-media/forced-colors/)」で説明しています。

`clip-path` で作った形は、要素の当たり判定も切り抜きます。切り抜いた外側はクリックできないので、タブの反り返りのような装飾は、この節の例のように背面の擬似要素に描き、タブ本体の当たり判定を変えないようにします（2026年10月、Chrome 152で確認）。
