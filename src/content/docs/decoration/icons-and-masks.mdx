三角形のような図形は、`border` の組み合わせではなく `clip-path` で描き、`polygon()` の値は `--shape--triangle-bottom` のような名前のトークンにします。単色のアイコンは、擬似要素の `mask-image` かインラインSVGで描き、どちらも文字色に合わせて塗ります。

マスクで描くなら `background-color` で塗り、インラインSVGなら `fill` や `stroke` を `currentColor` にします。文字色を変えるだけでアイコンも一緒に変わるので、状態ごとにアイコンの色を指定し直す必要がありません。意味を持つインラインSVGのアイコンは `aria-hidden="true"` にし、隣に視覚的に隠したテキストを置きます。

`clip-path` の `shape()` で輪郭を描く方法と、マスクの合成で枠線やドーナツグラフを描く方法は、「[16-5 輪郭と枠線を描く](/decoration/outlines/)」で説明しています。

## 図形は clip-path で描く

吹き出しの三角形のような図形は、`clip-path` で描きます。以前は、透明な `border` を組み合わせて三角形を作る方法がよく使われていました。

```css title="🙅‍♂ Not Recommended: border を組み合わせて三角形を作る"
/* 🙅‍♂ Not Recommended */
._tooltip {
  &::after {
    --_size: 16px;

    content: "";

    /* ... */
    border-block-start: calc(var(--_size) / 2 * tan(60deg)) solid;
    border-inline-start: calc(var(--_size) / 2) solid transparent;
    border-inline-end: calc(var(--_size) / 2) solid transparent;
  }
}
```

この方法では、三角形の大きさを3つの `border` の幅から逆算する必要があり、どの向きの三角形なのかもコードから読み取りにくくなります。`clip-path` なら、要素の幅と縦横比を決めて、形で切り抜くだけです。

```css title="🙆‍♂ Recommended: 形をトークンにして、clip-path で切り抜く"
:root {
  --shape--triangle-top: polygon(50% 0, 100% 100%, 0 100%);
  --shape--triangle-bottom: polygon(0 0, 100% 0, 50% 100%);
  --shape--triangle-right: polygon(0 0, 100% 50%, 0 100%);
  --shape--triangle-left: polygon(0 50%, 100% 0, 100% 100%);
}

._tooltip {
  position: relative;

  &::after {
    --_size: 16px;

    content: "";

    /* ツールチップの下端の中央から、下へ突き出す */
    position: absolute;
    inset-block-start: 100%;
    inset-inline-start: 50%;
    clip-path: var(--shape--triangle-bottom);
    inline-size: var(--_size);
    aspect-ratio: 2 / tan(60deg);
    background-color: inherit;
    translate: -50% 0;
  }
}
```

<Demo title="形のトークンで切り抜いた三角形と、下向きの三角形を付けたツールチップ" html={triangleHtml} css={triangleCss} />

三角形は、ツールチップの本体を基準に絶対配置します。絶対配置した擬似要素はブロックの箱になるので、`display` を指定しなくても、`inline-size` と `aspect-ratio` で大きさが決まります。`translate: -50% 0` で三角形の幅の半分だけ戻し、本体の中央にそろえます。

`polygon()` の値は直接書かず、トークンとして定義します。`polygon(0 0, 100% 0, 50% 100%)` という値を見て、下向きの三角形だとすぐに気づく人は多くないでしょう。`--shape--triangle-bottom` という名前なら、形がすぐに分かります。縦横比を `2 / tan(60deg)` にすると、正三角形になります（2026年10月、Chrome 152で確認）。{/* 要確認: Safari 18 と Firefox で、aspect-ratio の比に書いた tan() が効くか */}

### 2つの層を重ねて、選んだ範囲だけを切り抜く

`clip-path` は、図形を描くだけでなく、同じ大きさの層を2つ重ねて、上の層の一部だけを見せる使い方もできます。横に並んだタブで、選んだタブの背景色と文字色を変える場面で考えます。通常の色で描いたタブの列の上に、選んだときの色で描いた同じ列を重ね、上の列を選んだタブの範囲だけ切り抜きます。{/* 要確認: 出典なし */}

```css title="🙆‍♂ Recommended: 選んだときの色で描いた列を重ね、選んだタブの範囲だけを切り抜く"
@scope (.scoped.segmented-tabs) to (.scoped) {
  :scope {
    --_count: 3;
    --_index: 0;

    display: block grid;

    &:has(._tab:nth-child(2)[aria-selected="true"]) {
      --_index: 1;
    }

    &:has(._tab:nth-child(3)[aria-selected="true"]) {
      --_index: 2;
    }

    & > ._list,
    & > ._highlight {
      grid-area: 1 / 1;
    }
  }

  ._list,
  ._highlight {
    display: block grid;
    grid-auto-columns: 1fr;
    grid-auto-flow: column;
  }

  ._highlight {
    clip-path: xywh(calc(var(--_index) * 100% / var(--_count)) 0 calc(100% / var(--_count)) 100% round calc(infinity * 1px));
    background-color: var(--color--accent--600);
    color: var(--color--neutral--50);
    pointer-events: none;
  }
}
```

<Baseline id="rect-xywh" compatKey="css.types.basic-shape.xywh" name="xywh()" />

下の列（`._list`）は、`role="tab"` を付けた `<button>` を並べた、操作するためのタブです。上の列（`._highlight`）は見た目のためだけの複製なので、`aria-hidden="true"` で読み上げから外し、中身は `<span>` にしてフォーカスを受けないようにします。`pointer-events: none` で、クリックは下のタブに通します。どのタブを選んでいるかは、`aria-selected` から `:has()` で読み取り、`--_index` に入れています。

次のデモでは、タブを選ぶとスクリプトが `aria-selected` を付け替え、`:has()` で決まる `--_index` が変わります。上の列を切り抜く範囲が選んだタブに移り、背景と文字の色が一度で切り替わります。キーボードでは、左右の矢印キーでタブを移れます。

<Demo title="選んだときの色で描いた列を重ね、選んだタブの範囲だけを切り抜いて見せる" html={segmentedHtml} css={segmentedCss} js={segmentedJs} />

この方法では、選んだときの見た目を1つの列としてまとめて描けます。角丸の帯をタブの区切りと関係なく置くことも、列全体に掛けたグラデーションのうち選んだ範囲だけを見せることもできます。選択が変わったときに変わるのは、切り抜く範囲だけです。なお、`xywh()` の位置は左端から数えるので、右から左へ書く言語では、`:dir(rtl)` で位置の計算を反転させます。

この技法は、切り抜く範囲を `transition` で動かし、帯の移動に合わせて文字色が切り替わる演出として使われることがあります。しかし、本書では `clip-path` をペイントが起きるものとして扱います（「[18-7 動きの負荷を抑える](/motion/performance/)」）。切り抜きを動かすと、動いている間は毎フレーム描き直しが起きるので、切り抜く範囲は一度で切り替えます。

## アイコンをマスクで描く

単色のアイコンは、SVGを `mask-image` のマスクにして描けます。テンプレートでは、矢印のアイコンをdata URIのトークン（`--chevron--rightward` など）として定義し、擬似要素の `mask-image` で参照しています。色は `background-color` で塗るので、文字色やホバーの状態に合わせて変えられます。

```css title="🙆‍♂ Recommended: マスクで切り抜き、背景色で塗る"
._more {
  &::after {
    content: "";

    /* 空の擬似要素はインラインになり、幅と高さが効かないので、箱を作る */
    display: inline flow-root;
    mask-image: var(--chevron--rightward);
    mask-repeat: no-repeat;
    mask-position: center;
    mask-size: contain;
    inline-size: 1em;
    aspect-ratio: 1;
    background-color: var(--background-current);
  }
}
```

<Demo title="マスクで描いた矢印が、背景色に合わせた文字色で塗られる" html={maskIconHtml} css={maskIconCss} />

`display: inline flow-root` は、空の擬似要素に幅と高さを持たせるための指定です。親が `display: inline flex` のようなフレックスコンテナなら、擬似要素はフレックスアイテムとしてブロックの箱になるので、この指定がなくても描けます。

`background-color` に `currentColor` を直接書かず、`--background-current` から受け取っているのは、強制カラーモードでアイコンを消さないためです。この仕組みは「[15-5 強制カラーモードとコントラスト](/color-media/forced-colors/)」で説明しています。マスクのプロパティは、2023年12月までにすべての主要なブラウザが接頭辞なしで対応したので、`-webkit-` の接頭辞は要りません。

### スクロールできる領域の端をマスクで薄くする

横にスクロールできるタグやタブの列では、続きがあることを見た目で示します。端に線や影を付ける方法は、そこで区切られているように見え、続きがあることは伝わりにくくなります。背景と同じ色のグラデーションを端に重ねる方法は、背景が写真や別の色になると色がずれて、帯が浮いて見えます。{/* 要確認: 出典なし */}

端を薄くするときは、スクロールコンテナの `mask-image` に、両端が透明になるグラデーションを指定します。マスクは要素の中身そのものを透かすので、背景が何色でも、端の項目が途中で薄れて、続きがあるように見えます。マスクに使われるのはグラデーションの不透明度だけなので、`#000` は「そのまま見せる」範囲を表しているだけです。

```css title="🙆‍♂ Recommended: スクロールコンテナの両端を、マスクのグラデーションで薄くする"
@scope (.scoped.tag-scroller) to (.scoped) {
  ul {
    --_fade: 24px;

    display: block flex;
    gap: 8px;
    overflow-x: auto;
    mask-image: linear-gradient(to right, transparent, #000 var(--_fade), #000 calc(100% - var(--_fade)), transparent);
  }
}
```

グラデーションの向きには、`to inline-end` のような論理方向のキーワードがありません。Chrome 152では、`CSS.supports()` で `linear-gradient(to inline-end, …)` が無効と判定されました（2026年10月確認）。そこで、両端を同じ幅で薄くして、グラデーションを左右対称にします。右から左へ書く言語でも、同じ見た目になります。

マスクは、要素の境界の外に描かれるものも切り取ります。Chrome 152で確かめたところ、マスクを指定したスクロールコンテナの `outline` は表示されませんでした（2026年10月確認）。中にリンクのないスクロールコンテナは、キーボードでフォーカスを受けることがあり、そのときのフォーカスリングも見えなくなります。この場合は、親の要素に `&:has(> ul:focus-visible)` でリングを出します。リングを親に出す書き方は、「[17-1 状態とフォーカスを表す](/interaction/states-and-focus/)」のカード全体をリンクにする例と同じです。

上の例は、先頭までスクロールしていても、先頭の側の端を薄くします。スクロールできる方向の端だけを薄くするには、スクロールの位置を条件にする必要があります。方法は2つあります。1つは、スクロール駆動アニメーションで薄くする幅を変える方法です（「[18-6 スクロールに合わせて動かす](/motion/scroll-driven/)」）。もう1つは、`scroll-state(scrollable: inline-end)` のようなコンテナクエリで表示を切り替える方法です（「[11-5 固定ヘッダー](/layout-practice/sticky-header/#留まっている間だけ見た目を変える)」）。

## アイコンは currentColor で文字色に合わせる

インラインSVGのアイコンは、`fill` や `stroke` を `currentColor` にして、文字色に合わせます。ボタンの種類や状態ごとにアイコンの色を指定し直す必要がなくなり、文字色を変えるだけで、アイコンも一緒に変わります。

```css title="🙅‍♂ Not Recommended: 状態ごとにアイコンの色を指定し直す"
/* 🙅‍♂ Not Recommended */
button {
  color: var(--foreground--base);

  &:disabled {
    color: var(--foreground--muted);
  }
}

._icon {
  fill: var(--foreground--base);

  &:is(button:disabled *) {
    fill: var(--foreground--muted);
  }
}
```

```css title="🙆‍♂ Recommended: アイコンは文字色に合わせ、文字色だけを切り替える"
button {
  color: var(--foreground--base);

  &:disabled {
    color: var(--foreground--muted);
  }
}

._icon {
  fill: currentColor;
}
```

<Demo title="無効なボタンでは、文字色だけを変えると、アイコンと枠線も同じ色になる" html={currentColorHtml} css={currentColorCss} />

`border` の色を省略した場合も、初期値は `currentColor` です。文字と同じ色の枠線なら、`border: 1px solid` とだけ書けば足ります。色を2か所に書かなければ、片方だけ変え忘れることもありません。

アイコンの大きさは、`inline-size: 1em` と `aspect-ratio: 1` で文字の大きさに合わせます。テンプレートでは `.icon` というクラスで、`--icon--size` を受け取れるようにしています。アイコンを画面の幅に合わせて変える必要がないことは、「[13-1 検討する順番](/responsive/escalation/)」で説明しています。

### インラインSVGの代替テキスト

意味を持つアイコンをインラインSVGで置くときは、SVGに `aria-hidden="true"` を付けて読み上げの対象から外し、隣に視覚的に隠したテキストを置きます。

```html
<a href="https://example.com/" target="_blank">
  関連資料
  <svg class="icon" aria-hidden="true" viewBox="0 0 24 24" fill="none" stroke="currentColor">
    <path d="M17 2H22V7" />
    <path d="M13 11L21.5 2.5" />
  </svg>
  <span class="-visually-hidden">新しいウィンドウが開きます</span>
</a>
```

SVGの中の `<title>` や `aria-label` で名前を付ける方法もありますが、これらは機械翻訳されず、ページ内検索の対象にもなりません。ふつうのテキストとして置けば、翻訳、検索、選択してのコピーのすべてに対応できます。視覚的に隠すユーティリティは「[10-3 コンポジションとユーティリティ](/components/compositions-and-utilities/)」で扱います。

### 単色のアイコンの描き方を選ぶ

単色のアイコンを置く方法は、擬似要素の `mask-image`、インラインSVG、外部のファイルを読み込む `<img>` の3つです。どれを選ぶかは、文字色に合わせたいか、HTMLにアイコンを書けるかで決まります。違いを次の表にまとめます。

| 方法 | 色を文字色に合わせる | 強制カラーモード | 代替テキスト | 向く場面 |
| --- | --- | --- | --- | --- |
| 擬似要素の `mask-image` | `background-color` で合わせられる | 背景色が消えるので、`--background-current` でシステムカラーに戻す | 持てない。意味があれば隣にテキストを置く | 矢印や外部リンクの印のように、CSSだけで足す装飾 |
| インラインSVG | `fill` や `stroke` の `currentColor` で合わせられる | 色が置き換わらないことがあるので、`fill` と `stroke` をシステムカラーに固定する | `aria-hidden="true"` にして、隣に視覚的に隠したテキストを置く | 意味のあるアイコンや、線と塗りを使い分ける複雑な形 |
| 外部のファイルの `<img>` | 合わせられない。画像の中の色のまま | 影響を受けないので、背景に溶け込むなら `filter` で塗りつぶす | `alt` 属性で付ける | 色を変えないロゴや、多色の画像 |

{/* 要確認: 出典なし（「向く場面」の列と、<img> のSVGがページの文字色を受け取らないこと） */}

文字色に合わせる必要があるアイコンは、`mask-image` かインラインSVGのどちらかになります。HTMLに手を入れずにCSSだけで足したい装飾なら `mask-image` を、HTMLの中で意味を持たせたいアイコンならインラインSVGを選びます。強制カラーモードの補正は、どちらも「[15-5 強制カラーモードとコントラスト](/color-media/forced-colors/)」で説明しています。
