この章では、ユーザーの操作に反応する部分のCSSを扱います。ホバーやフォーカスの状態の表し方、ダイアログやアコーディオンのような開閉するUI、フォーム部品、カルーセルです。インタラクションはできるだけブラウザの機能に任せ、CSSでは見た目を足すことに徹します。

操作に関わるUIは、見た目が同じでも使いやすさが変わります。キーボードで操作できるか、スクリーンリーダーで状態が読み上げられるか、ページ内検索で中身が見つかるかといった違いがあるからです。以前は、こうした振る舞いの多くをJavaScriptで作り直す必要がありました。現在は、`<dialog>` の `command` 属性や `popover` 属性、`<details>` の `name` 属性のように、HTMLとCSSだけで実現できることが増えています。

私自身、少し前まではモーダルの開閉や背景のクリックの判定をJavaScriptで書いていました。入力エラーの表示も、`:invalid` ではページを開いた時点でエラーが出てしまうので、JavaScriptで管理していました。どちらも、いまはブラウザの機能で置き換えられます。

この章は次の4つの節で構成しています。

- [16-1 状態とフォーカスを表す](/interaction/states-and-focus/)：`any-hover` によるホバーの書き方、`:focus-visible` との対応、ARIA属性による状態の表し方、カード全体をリンクにする方法
- [16-2 開閉するUI](/interaction/disclosure/)：`<dialog>`、`popover` 属性、`<details>`、`hidden="until-found"` の使い分け
- [16-3 フォーム部品](/interaction/forms/)：`accent-color`、`input` 自体に描くチェックボックス、`switch` 属性、`:user-invalid`、入力欄の文字サイズ
- [16-4 CSSでカルーセルを作る](/interaction/carousel/)：スクロールスナップを土台にした `::scroll-button()` と `::scroll-marker`、隠れているスライドを外す `interactivity: inert`、自動再生をしない判断

トランジションとアニメーション、開閉するUIの出現と退場の動き、View Transitionsによる画面の切り替えは、第17章「[モーション](/motion/)」で扱います。フォーカスリングの定義、スムーススクロール、モーダル表示中の背面の固定は、ベーススタイルに書くものとして「[6-2 ベーススタイルに書くもの](/reset/base-styles/)」で扱います。強制カラーモードでの部品の見え方は「[14-5 強制カラーモードとコントラスト](/color-media/forced-colors/)」で扱います。この章のコード例では、説明に関係しない `@layer` の記述を省略しています。デモのCSSには省略せずに書いています。

## 最初に押さえるルール

{/* 要確認: 著者の優先順位で選び直す（レビューの提案にもとづく下書き） */}

次のルールを先に押さえ、ほかのルールは、該当する場面で付録A「[ルール一覧](/appendix/rules/)」から引けば足ります。

- [`hover-with-focus-visible`](/interaction/states-and-focus/#rule-hover-with-focus-visible)：ホバーで変える見た目は、`:focus-visible` にも同じように指定します。
- [`hover-inside-any-hover`](/interaction/states-and-focus/#rule-hover-inside-any-hover)：`:hover` のスタイルは `@media (any-hover)` の中に書き、`(hover: hover)` や画面の幅で判定しません。
- [`hover-only-when-operable`](/interaction/states-and-focus/#rule-hover-only-when-operable)：ホバーのスタイルは、`:any-link:hover` や `:enabled:hover` のように、操作できる状態に限定して書きます。
- [`hide-panels-after-init`](/interaction/disclosure/#rule-hide-panels-after-init)：開閉するパネルは初期のHTMLでは隠さず、開閉の処理の初期化が成功してからJavaScriptで隠します。
- [`no-maximum-scale`](/interaction/forms/#rule-no-maximum-scale)：入力欄での拡大を防ぐために、`maximum-scale` や `user-scalable=no` でズームを止めません。
