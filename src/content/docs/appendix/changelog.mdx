本書の版ごとの変更点をまとめたページです。本書はバージョン番号で版を管理していて、ルールを変えたり削除したりしたときはメジャーバージョンを、ルールを追加したときはマイナーバージョンを、文章の修正だけのときはパッチバージョンを上げます。

AI向けのルール集やスキルには、生成したときのバージョンと日付が入っています。手元にコピーしたルール集が古くなっていないかは、このページの最新のバージョンと見比べて確かめてください。

執筆中の版は `0.x` とし、すべての章の内容を著者が確認した時点で `1.0.0` にする予定です。`0.x` の間は、ルールを変えたり削除したりしたときも、マイナーバージョンを上げます。

## 0.14.0（2026年10月2日）

名前に使う略語と数字の扱いを決めました。ルールを1件追加し、1件の内容を変えたため、マイナーバージョンを上げています。

- 「[6-6 名前に使う語](/notation/terminology/)」に、省略語と数字の扱いを加えました。クラス名に数字を使わないことと、概念がはっきりしてから名前を付けることは、ECSSのルールにもとづいています。
- ルール [`no-numbers-in-class-names`](/notation/terminology/#rule-no-numbers-in-class-names) を追加しました。クラス名に番号を使わず、役割の名前、属性、`:nth-child()` で区別します。
- ルール [`no-abbreviation`](/notation/terminology/#rule-no-abbreviation) の内容を変えました。対象にカスタムプロパティの名前を加え、省略してよい略語を、`img` のようにWeb標準で使われている略語と、`cta` のようにプロジェクトの中で浸透している略語に限りました。このルールの掲載先は、6-1から6-6に移しています。

## 0.13.0（2026年10月2日）

名前に使う語の節を加え、本書全体のクラス名を命名のルールに合わせて直しました。ルールを追加し、ルール1件の補足を変えたため、マイナーバージョンを上げています。

- 第6章に「[6-6 名前に使う語](/notation/terminology/)」を加えました。著者のデザインシステムの用語の指針をもとに、`inner` と `outer`、`container`、`gutter` と `gap`、`columns`、`link` と `button`、`navigation` と `menu` の意味と使い分けをまとめています。
- 「[6-1 命名規則](/notation/naming/)」に、バリエーションの軸が2つ以上あるときの属性の分け方を加えました。
- 「[8-9 余白を設計する](/layout/spacing/)」に、ページに並べるセクションの上下の余白の作り方を加えました。
- 第12章「[画像・装飾](/decoration/)」の3ページに、デモを加えました。
- 第7章の[概要](/components/)に、OOCSS、BEM、SMACSS、FLOCSSとの対応を加えました。
- ルールを9件追加しました。
  - [`one-term-one-meaning`](/notation/terminology/#rule-one-term-one-meaning)：名前に使う語は、プロジェクトの中で1つの意味だけで使います。
  - [`inner-outer-names`](/notation/terminology/#rule-inner-outer-names)：`inner`、`outer`、`container` には、`._section-inner` のように必ず「何の」を併記します。
  - [`gutter-vs-gap`](/notation/terminology/#rule-gutter-vs-gap)：画面の端との余白は `gutter`、子要素どうしの間隔は `gap` と呼び、取り違えません。
  - [`columns-for-multicol`](/notation/terminology/#rule-columns-for-multicol)：`columns` の語は段組みにだけ使い、`row` を要素の名前にしません。
  - [`navigation-not-menu`](/notation/terminology/#rule-navigation-not-menu)：サイトの導線は `navigation`、操作の選択肢の一覧は `menu` と呼びます。
  - [`no-text-only-name`](/notation/terminology/#rule-no-text-only-name)：`text` だけの名前を付けません。
  - [`renaming-terms-is-breaking`](/notation/terminology/#rule-renaming-terms-is-breaking)：公開プロパティやコンポーネントの名前に使った語の変更は、互換性のない変更として扱います。
  - [`variant-attribute-per-axis`](/notation/naming/#rule-variant-attribute-per-axis)：独立したバリエーションの軸は、軸ごとに別の属性で表します。
  - [`section-padding-block`](/layout/spacing/#rule-section-padding-block)：ページに並べるセクションの上下の余白は、各セクションのルートの `padding-block` で作ります。
- ルール [`no-vague-names`](/notation/naming/#rule-no-vague-names) の補足の例を、`_inner` から `_section-inner` に変えました。
- 本書のコード例とデモのクラス名を、命名のルールに合わせて直しました。`._inner` には「何の」を併記し、`._columns`、`._row`、`._text` のような名前を役割の名前に変えています。`._list`、`._link`、`._button`、`li` の `._item` のように要素の種類を言い換えただけのクラスは、タイプセレクタか役割の名前に変えました。

  - [`component-decision-tests`](/components/what-is-a-component/#rule-component-decision-tests)：コンポーネントにするかは、繰り返し使うか、全インスタンスで構造や振る舞いを制御したいか、既知の構造の拡張があるか、の順に判定します。

- 文字色を背景の明度から選ぶ `sign()` の式を、`oklch(from var(--_foreground) sign(0.7 - l) 0 h)` にそろえました。
- コンポジション「[8-14-10 primary-layout](/layout/compositions/primary-layout/)」から、画面モードのスタイルクエリによる分岐を外しました。公開プロパティは `--primary-layout--gutter` のように接尾辞のない1組になり、デフォルト値は旧 `--compact` の値です。
- 用語集に「通常フロー」と「ブロック整形コンテキスト」を加えました。

## 0.11.1（2026年10月2日）

本書のコード例とデモが本書のルールに従っていない箇所を、すべての章で直しました。ルールの追加や意味の変更はないため、パッチバージョンを上げています。

- 初期値、ブラウザのデフォルトスタイル、kiso.css、継承で決まる値を指定し直している宣言を消しました（[`no-redundant-defaults`](/principles/maintainability/#rule-no-redundant-defaults)）。主な対象は、`border` の `currentColor` や `1px solid`、リストの `padding` と `list-style-type`、見出しの `margin` です。リンクの `text-decoration` や、`fieldset` と `legend` の余白も消しています。
- 値を戻す宣言を、`0` や `none` ではなく、戻したい先に合うキーワード（`initial`、`unset`、`revert`、`revert-layer`）で書くようにしました（[`explicit-rollback-keyword`](/cascade/cascade-basics/#rule-explicit-rollback-keyword)）。
- Not Recommendedの例を、教えたい点のほかは本書の書き方に揃えました。例の主題が古いコード全体のものは、そのままにしています。
- このほか、`font-weight: bold` を `700` に、幅いっぱいに広げる `inline-size: 100%` を `stretch` に、物理プロパティを論理プロパティに直しました。`div` には役割のクラスを付け、`img` には `width` と `height` の属性を加えています。
- 「[7-1 コンポーネントの境界を守る](/components/boundaries/)」と「[6-4 モダンな記法にそろえる](/notation/modern-syntax/)」のホバーの例に `:focus-visible` を加え、7-1の詳細度の説明を直しました。ルール [`type-selector-in-scope`](/components/boundaries/#rule-type-selector-in-scope) の補足の例も合わせています。
- 「[13-3 CMSのWYSIWYG本文にスタイルを当てる](/operations/wysiwyg/)」のコード例とデモから、`@layer` を外しました（[`no-layers-with-unlayered-css`](/cascade/layers/#rule-no-layers-with-unlayered-css)）。

## 0.11.0（2026年10月2日）

単位のついた値での割り算を使うことにし、`stretch` とパターンについてのルールを追加しました。ルールの主張が反対になったものがあるため、旧ルールを削除して新しいルールに置き換えています。

- ルールを1件削除しました。
  - `no-typed-arithmetic`：単位のついた値どうしの割り算（typed arithmetic）を使わない
- ルールを3件追加しました。
  - [`typed-arithmetic-to-unitless`](/values/math-functions/#rule-typed-arithmetic-to-unitless)：長さを単位のない数値に変えるときは、`tan(atan2(長さ, 1px))` ではなく、`calc(100svi / 1px)` のように単位のついた値で割ります。
  - [`stretch-over-width-100`](/principles/maintainability/#rule-stretch-over-width-100)：幅いっぱいに広げる指定が要る要素には、`inline-size: 100%` ではなく、`-webkit-fill-available` と `stretch` をこの順に書きます。
  - [`pattern-leaves-component-properties`](/components/compositions-and-utilities/#rule-pattern-leaves-component-properties)：パターンには重ねるコンポーネントが指定しないプロパティだけを書き、コンポーネントの側で変える値は公開プロパティで受け取ります。
- ルールの補足を3件更新しました。[`no-redundant-defaults`](/principles/maintainability/#rule-no-redundant-defaults) には、その文脈でブラウザが無視するプロパティも消すことを加えました。[`composition-class-plain`](/notation/naming/#rule-composition-class-plain) には、パターンにも接頭辞を付けず、コンポジションは配置の名前、パターンは役割の名前で区別することを加えました。
- 「[4-3 計算関数で根拠を式に残す](/values/math-functions/)」で、typed arithmeticの対応状況を「Safari 26以降」から「Safari 18.2以降」に正しました。あわせて、Chromeでは割り算で定義した長さがブラウザのズームで拡大縮小されない注意を加えました。9-4の式とデモも、単位のついた値での割り算に書き換えています（[9-4 実践パターン：2サイズのデザインカンプを再現する](/responsive/design-comp-pattern/)）。
- 「[1-2 保守しやすさを最優先にする](/principles/maintainability/)」に、`div` が親の幅に広がる仕組みの説明を加えました。「[8-2 ボックスモデルの基礎](/layout/box-model/)」と「[12-4 フォーム部品](/interaction/forms/)」の `stretch` の対応状況を改め、1-2にリンクしています。
- 「[3-2 :has() で祖先と前の兄弟を選ぶ](/pseudo/has/)」で、`:has()` と `:not()` を組み合わせたセレクタを読み解く手順を書き直しました。
- 「[5-1 壊さないリセット](/reset/kiso/)」の冒頭に、初期値、ブラウザのデフォルトスタイル、作者のCSSの3層と、リセットCSSの変遷を説明する節を加えました。
- 「[6-1 命名規則](/notation/naming/)」のクラス名の表にパターンを加え、4種類から5種類にしました。「[7-2 コンポジションとユーティリティ](/components/compositions-and-utilities/)」に、節「パターンに書いてよいプロパティ」を加えています。パターンの内部プロパティは `--_p--` で始めることにし、[`internal-property-prefix`](/components/custom-properties/#rule-internal-property-prefix) の補足に加えました。
- 「[11-5 輪郭と枠線を描く](/decoration/outlines/)」のドーナツグラフの式を、単位のついた値での割り算に書き換えました。
- 「[付録B モダンな書き方への置き換え表](/appendix/modernize/)」、「[付録C Sassの機能を素のCSSで置き換える](/appendix/sass/)」、「[付録D レビューのチェックリスト](/appendix/checklist/)」を、新しいルールに合わせました。

- 「[11-4 フォーム部品](/interaction/forms/)」で、スイッチの代わりに `<button>` と `aria-pressed` を勧めていた説明を、`role="switch"` を使う説明に直しました。
