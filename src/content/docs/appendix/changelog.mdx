本書の版ごとの変更点をまとめたページです。本書はバージョン番号で版を管理していて、ルールを変えたり削除したりしたときはメジャーバージョンを、ルールを追加したときはマイナーバージョンを、文章の修正だけのときはパッチバージョンを上げます。

AI向けのルール集やスキルには、生成したときのバージョンと日付が入っています。手元にコピーしたルール集が古くなっていないかは、このページの最新のバージョンと見比べて確かめてください。

執筆中の版は `0.x` とし、すべての章の内容を著者が確認した時点で `1.0.0` にする予定です。`0.x` の間は、ルールを変えたり削除したりしたときも、マイナーバージョンを上げます。

## 0.21.0（2026年10月5日）

Web Componentsと表の組み方を扱う節を加え、新しいCSSの機能、文字の切り詰め、モーションの判断基準などを各章に補いました。ルールを32件追加したため、マイナーバージョンを上げています。既存の節の番号とURLは変わっていません。

- 節を3つ加えました。
  - 「[8-6 Web Components](/components/web-components/)」：カスタム要素そのものをルートにし、`@scope (<要素名>.scoped) to (.scoped)` で閉じる書き方を説明しています。JavaScriptがなくても動くHTMLを先に作る順番も書きました。ページから子要素を受け取る部品はLight DOMで、中身をすべて自分で描く部品はShadow DOMで作る、という使い分けも示しました。
  - 「[10-15 表を組む](/layout/tables/)」：表をスクロールのラッパーで包む書き方、見出しのセルを `position: sticky` で留める条件、数値の列のそろえ方、狭い幅で縦に積む組み方を説明しています。
  - 「[10-16 文字の切り詰めと読み込み中の表示](/layout/truncation-and-skeletons/)」：1行の切り詰めに必要な指定、全文を読める手段、数値を切り詰めない理由、スケルトンを読み込み後と同じ寸法にする書き方を説明しています。
- 「[2-3 カスケードレイヤーで順位を決める](/cascade/layers/)」に、`@import` をビルド時に展開する理由を加えました。「[2-4 @scopeでスタイルを閉じ込める](/cascade/scope/)」には、Shadow DOMとの使い分けを加えています。
- 第3章の「[3-4 子要素の位置で選ぶ](/pseudo/child-index/)」に `sibling-index()` と `sibling-count()` を、「[3-8 生成コンテンツと装飾の擬似要素](/pseudo/generated-content/)」に `::highlight()` を加えました。
- 「[4-3 計算関数で根拠を式に残す](/values/math-functions/)」に、流体的な文字サイズの最大値と最小値の比と、Chrome系のブラウザだけが対応する `calc-size()` と `@function` を採用しない理由を加えました。
- 「[10-7 positionの基礎](/layout/positioning/)」に、留まると大きさが変わる要素とスクロールアンカリングの関係を加えました。
- 「[13-1 フォントを指定する](/typography/fonts/)」に `font-size-adjust` を、「[13-4 文字サイズと改行](/typography/size-and-line-breaks/)」に `text-wrap: balance` を指定しない要素を加えました。
- 「[14-3 背景から文字色を決める](/color-media/contrast-text/)」に閾値を0.7にする根拠を、「[14-4 ダークモード](/color-media/dark-mode/)」に一部のコンポーネントだけを暗い配色にする方法を加えました。
- 「[15-1 画像と装飾](/decoration/images-and-decoration/)」に、スクロールできる領域の端をマスクで薄くする方法と、2つの層を重ねて選んだ範囲だけを切り抜く方法を加えました。
- 「[16-1 状態とフォーカスを表す](/interaction/states-and-focus/)」に、`user-select` と `touch-action` を指定する範囲を加えました。「[16-3 フォーム部品](/interaction/forms/)」には `appearance: base-select` を、「[16-4 CSSでカルーセルを作る](/interaction/carousel/)」には `scroll-target-group` を加えています。
- 第17章では、「[17-1 動かすかどうかを決める](/motion/purpose/)」に使う頻度の目安を加えました。「[17-5 出現と退場](/motion/entry-and-exit/)」には頻度の低いUIで要素をずらして出す方法を、「[17-7 動きの負荷を抑える](/motion/performance/)」には `content-visibility` を加えています。「[17-6 スクロールに合わせて動かす](/motion/scroll-driven/)」の `@supports` の条件には、`animation-range` を加えました。

  - [`tabular-nums-for-number-columns`](/layout/truncation-and-skeletons/#rule-tabular-nums-for-number-columns)：縦に並ぶ数値と、変わり続ける数字には `tabular-nums` を指定します。
  - [`table-min-size-with-scroller`](/layout/tables/#rule-table-min-size-with-scroller)：表は縮めずに最小の幅を決め、包む要素で横にスクロールさせます。

  - [`sticky-table-header-needs-block-limit`](/layout/tables/#rule-sticky-table-header-needs-block-limit)：ラッパーの中で列の見出しを留めるときは、ラッパーに `max-block-size` を指定します。
  - [`table-sticky-border-separate`](/layout/tables/#rule-table-sticky-border-separate)：見出しのセルを留めるときは、`border-collapse: separate` にして枠線を各セルに持たせます。

  - [`stacked-table-aria-roles`](/layout/tables/#rule-stacked-table-aria-roles)：表を縦に積むときは、各要素に `role` を書きます。

## 0.20.0（2026年10月3日）

`@scope` とネスト、擬似クラス、記法、レスポンシブデザインの章の構成を見直し、サイズを問い合わせる `@container` を「コンテナサイズクエリ」と呼ぶことにしました。コンポーネントのルートのコンテナ名も `--scoped` にそろえています。ルールを追加し、変更し、削除したため、マイナーバージョンを上げています。第3章、第7章、第12章の節の番号と、一部の節のURLも変わりました。

- 節を6つ加え、1つを書き直しました。
  - 「[2-5 CSSネストの基礎](/cascade/nesting/)」：`&` の意味と詳細度を、親のセレクタリストを包んだ `:is()` に置き換えて読む方法を説明しています。`@scope` はBEMのBlockとElementの関係に、ネストはElementとModifierの関係に向いている、という対比も示しました。
  - 「[3-2 :is()・:where()・:not()](/pseudo/is-where-not/)」：3つの擬似クラスの詳細度と、`:not()` の引数の書き方を説明しています。旧3-2〜3-7は、3-3〜3-8になりました。
  - 「[7-3 @scopeとネストの使い分け](/notation/scope-and-nesting/)」：2-4にあった `@scope` の規約を移し、下限に具体的な要素名や別のコンポーネント名を書かない理由、下限の3案の比較、付け忘れを防ぐ手段を加えました。
  - 「[7-4 ネストの書き方](/notation/nesting/)」と「[7-6 プロパティの並び順](/notation/property-order/)」：旧7-2「ネストとプロパティの並び順」を2つの節に分けました。
  - 「[12-2 ブレイクポイントの決め方](/responsive/breakpoints/)」：中身から閾値を導く `calc(10rem * 6 + 1.5rem * 5)` の式を中心にしました。`gap` と `padding` を式から省かないこと、`calc()` を使う判断の基準、AIの出力を確かめる観点も説明しています。
  - 「[12-3 コンテナサイズクエリ](/responsive/container-size-queries/)」：旧12-2「コンテナクエリ」を書き直しました。ルートを `--scoped` という名前のコンテナにする書き方、同じ閾値をスタイルクエリで子孫に伝える方法、最後の手段としての `zoom` と `progress()` を加えています。
- 第7章の節を並べ替えました。旧7-7「名前に使う語」を7-2に、旧7-3〜7-6を7-5、7-7〜7-9にしています。
- 第12章の旧12-3「メディアクエリとブレイクポイント」を「[12-4 メディアクエリ](/responsive/media-queries/)」に改め、メディア特性を使う・使わない・まだ使えないに分けた一覧を加えました。旧12-4〜12-6は、12-5〜12-7になりました。
- 「[2-2 セレクタで詳細度を設計する](/cascade/selectors/)」に、`:is()`、`:not()`、`:has()`、`:nth-child(… of S)`、`:where()` の詳細度の表を加えました。「[2-4 @scopeでスタイルを閉じ込める](/cascade/scope/)」は仕様の説明に絞り、下限のない `@scope` とネストや `:where()` との比較、スコープの近接度を加えました。
- 「[3-5 数量クエリ](/pseudo/quantity-queries/)」に、最終行の端数を中央に寄せる例を加えました。
- 「[10-3 ボックスモデルの基礎](/layout/box-model/)」には、最大幅と `padding` で中央に寄せる要素の内容の幅を、`box-sizing: unset` で最大幅にそろえる書き方を加えました。「[10-5 Flexboxの基礎](/layout/flexbox-basics/)」には、`flex: 1` でもアイテムの幅がそろわない場合を加えました。
- 「[15-3 輪郭と枠線を描く](/decoration/outlines/)」に、擬似要素と `mask-composite: exclude` でグラデーションの角丸の枠線を描く方法を加えました。
- 「[17-6 スクロールに合わせて動かす](/motion/scroll-driven/)」を書き直しました。画面に入ったら再生する演出は、CSSだけで書く方法（`view()` のタイムラインとスタイルクエリ）を基本にしています。
- URLを変えました。
  - `/notation/nesting-and-order/` を、`/notation/nesting/` と `/notation/property-order/` に分けました。
  - `/responsive/container-queries/` を `/responsive/container-size-queries/` に変えました。
- ルールを11件追加しました。
  - [`nesting-read-as-is`](/cascade/nesting/#rule-nesting-read-as-is)：ネストしたセレクタの意味と詳細度は、`&` を `:is()` に置き換えて確かめ、Sassの展開結果として読みません。
  - [`not-selector-list`](/pseudo/is-where-not/#rule-not-selector-list)：複数の条件を除くときは、`:not(.a):not(.b)` と重ねず、`:not(.a, .b)` と書きます。
  - [`not-ancestor-in-argument`](/pseudo/is-where-not/#rule-not-ancestor-in-argument)：「Xの中にない要素」は、`&:not(X *)` のように祖先を `:not()` の引数の中に書きます。
  - [`unset-box-sizing-for-content-max-width`](/layout/box-model/#rule-unset-box-sizing-for-content-max-width)：内容の幅を最大幅にそろえるときは、`calc()` で `padding` を足さず、`box-sizing: unset` で `content-box` に戻します。
  - [`threshold-includes-gap-and-padding`](/responsive/breakpoints/#rule-threshold-includes-gap-and-padding)：閾値の式には、`gap`、`padding`、`border` を省かずに含めます。
  - [`no-container-just-in-case`](/responsive/container-size-queries/#rule-no-container-just-in-case)：`container` は、実際に問い合わせる要素にだけ指定します。
  - [`density-via-style-query`](/responsive/container-size-queries/#rule-density-via-style-query)：同じ閾値を何度も使うときは、ルートの直下の要素で `--_density` を宣言し、子孫は `@container style()` で切り替えます。
  - [`no-orientation-for-layout`](/responsive/media-queries/#rule-no-orientation-for-layout)：レイアウトの切り替えを `orientation` で判定せず、`width` で判定します。
  - [`gradient-border-method`](/decoration/outlines/#rule-gradient-border-method)：グラデーションの枠線は `background-clip: border-area` で描き、どの環境でも必要なときだけ擬似要素と `mask-composite: exclude` を使います。
  - [`hover-operable-in-any-hover`](/interaction/states-and-focus/#rule-hover-operable-in-any-hover)：ホバーのスタイルは、`&:any-link:hover` や `&:enabled:hover` のように操作できる状態に限定し、`@media (any-hover)` の中に書きます。
  - [`reveal-once-with-style-query`](/motion/scroll-driven/#rule-reveal-once-with-style-query)：画面に入ったら1回だけ再生する演出は、`view()` のタイムラインで切り替えたカスタムプロパティを `@container style()` で問い合わせて作ります。
- ルールの内容を変えました。
  - [`container-name-required`](/responsive/container-size-queries/#rule-container-name-required)：ルートのコンテナ名を `--scoped` に、子要素のコンテナ名をクラス名から下線を除いた名前に決め、外側のコンポーネントのコンテナを問い合わせないことを加えました。[`container-name-dashed-ident`](/responsive/container-size-queries/#rule-container-name-dashed-ident) の例も合わせました。
  - [`quantity-query-with-has`](/pseudo/quantity-queries/#rule-quantity-query-with-has)：親や兄弟の見た目を変えるときは `:has()`、数えた子要素そのものを変えるときは `:nth-child()` と `:nth-last-child()` の組み合わせを使う、と改めました。[`quantity-query-for-count-conditions`](/pseudo/quantity-queries/#rule-quantity-query-for-count-conditions) には、最終行の端数を中央に寄せる例を加えました。
  - [`threshold-as-formula`](/responsive/breakpoints/#rule-threshold-as-formula)：「中身の幅＋`padding`＋`border`」の例と、式にする判断の基準を加え、AIが誤りやすいルールにしました。
