この章では、擬似クラスと擬似要素を扱います。擬似クラスは、要素の状態、兄弟の中での位置、子の数のように、HTMLのクラスや属性には書かれていない条件で要素を選ぶセレクタです。擬似要素は、段落の1行目や入力欄のプレースホルダーのような要素の一部と、`::before` や `::after` のようにCSSで生成した箱を選びます。それぞれの仕組みと、似た書き方のどれを選ぶかの基準を示します。

この章で置き換えたいのは、状態を表すためにJavaScriptでクラスを付け外しする処理です。チェックされたラジオボタンを含むカードに `is-checked` を付ける処理や、画像を持つカードに `has-image` を付ける処理は、HTMLの状態とクラスの2か所に同じ情報を持たせます。付け外しの処理を書き漏らすと、見た目と中身が食い違います。`:checked` や `:has()` のような擬似クラスを使えば、ブラウザの管理するHTMLの状態をそのままセレクタで参照できます。情報は1か所にしかないので、ずれることはありません。

一方で、擬似クラスには、意味を取り違えやすいものや、照合の対象を広げやすいものがあります。`:has()` と `:not()` は入れ子の順序で意味が逆になり、起点のない `:has()` はページのすべての要素を照合の対象にします。`:nth-child()` と `:nth-of-type()` も、数える対象が違います。この章では、どの条件のときに当てはまるかを例で確かめながら、取り違えにくい書き方をルールにします。

この章は次の7つの節で構成しています。

- [3-1 擬似クラスと擬似要素の基本](/pseudo/basics/)：擬似クラスと擬似要素の違い、コロンの数、詳細度の数え方
- [3-2 :has() で祖先と前の兄弟を選ぶ](/pseudo/has/)：子の有無や状態で祖先を変える書き方と、起点と引数の範囲の絞り方
- [3-3 子要素の位置で選ぶ](/pseudo/child-index/)：`:first-child`、`:nth-child()`、`:nth-child(… of S)` などで、兄弟の中の位置を条件にする書き方
- [3-4 数量クエリ](/pseudo/quantity-queries/)：子の数に応じてレイアウトを切り替えるセレクタ
- [3-5 フォームの状態を表す擬似クラス](/pseudo/form-states/)：`:checked`、`:disabled`、`:user-invalid`、`:placeholder-shown` などが当てはまる条件の違い
- [3-6 開閉と表示の状態を表す擬似クラス](/pseudo/open-states/)：`:open`、`:popover-open`、`:modal`、`:target` などが当てはまる条件の違い
- [3-7 生成コンテンツと装飾の擬似要素](/pseudo/generated-content/)：`::before` と `::after` の使いどころ、`::first-letter` や `::selection` などの装飾の擬似要素

`:where()` と `:is()` による詳細度の調整は、第2章「[2-2 セレクタで詳細度を設計する](/cascade/selectors/)」で説明しています。この章では、擬似クラスが「どの状態のときに当てはまるか」に絞り、それを使ったUIの実装は第12章に渡します。`:hover`、`:focus-visible`、`:focus-within` によるフォーカスの表し方は「[13-1 状態とフォーカスを表す](/interaction/states-and-focus/)」で、ダイアログやアコーディオンの開閉は「[13-3 開閉するUI](/interaction/disclosure/)」で扱います。フォーム部品の作り方は「[13-4 フォーム部品](/interaction/forms/)」で、カルーセルは「[13-6 CSSでカルーセルを作る](/interaction/carousel/)」で説明しています。番号付きリストのマーカーを `::marker` で装飾する方法は、第12章「[12-1 画像と装飾](/decoration/images-and-decoration/)」で説明しています。

## この章で扱わない擬似要素と擬似クラス

この章では、主要なブラウザの一部でしか使えないものと、サイト制作の範囲から外れるものは扱いません。次に挙げるものは、名前と対応状況（2026年10月確認）と、扱わない理由だけを示します。{/* 要確認: 出典なし */}

`::scroll-marker` と `::scroll-button()` は、スクロールコンテナにインジケーターとページ送りのボタンを生成する擬似要素です。対応しているのはChromeとEdgeの135以降だけで、Baselineではありません。カルーセルを作るときにだけ使うものなので、使い方と未対応の環境への備えは、第13章「[13-6 CSSでカルーセルを作る](/interaction/carousel/)」でまとめて説明します。段組みの列ごとに箱を生成する `::column` も、同じくChromeとEdgeの135以降だけが対応しており、現時点ではカルーセルの列ごとにスクロールマーカーやスナップ位置を指定するためのものなので扱いません。

`::picker(select)` と `::checkmark` は、`appearance: base-select` を指定した `<select>` のドロップダウンと、選んだ項目の印を選ぶ擬似要素です。対応しているのはChrome 135以降（`::checkmark` は133以降）とSafari 27で、Firefoxが対応していないためBaselineではありません。`<select>` の見た目を変える方法は、第13章「[13-4 フォーム部品](/interaction/forms/)」で現状を示すにとどめています。

`:state()` は、カスタム要素がJavaScriptで設定した独自の状態を選ぶ擬似クラスです。2024年5月にすべての主要なブラウザが対応し、Baseline Newly availableになっています。ただし、使うにはカスタム要素を定義し、`ElementInternals` で状態を管理する必要があり、本書の題材であるHTMLとCSSによるサイト制作から外れるので扱いません。

`interestfor` 属性は、ボタンやリンクにホバーやフォーカスで「関心」を示したとき、ツールチップのような要素を表示する仕組みです。関連する擬似クラスとして `:interest-source` と `:interest-target` があります。対応しているのはChromeとEdgeの142以降だけで、Baselineではないので扱いません。

## 最初に押さえるルール

{/* 要確認: 著者の優先順位で選び直す */}

次のルールを先に押さえ、ほかのルールは、該当する場面で付録A「[ルール一覧](/appendix/rules/)」から引けば足ります。

- [`no-unanchored-has`](/pseudo/has/#rule-no-unanchored-has)：`:has()` は、`&:has(> img)` や `.card:has(> img)` のように直前に起点を書き、起点のない `:has()` は書きません。
- [`has-narrow-anchor`](/pseudo/has/#rule-has-narrow-anchor)：`:has()` の起点はコンポーネントのルートのような狭い要素にし、引数は `>` や `+` の結合子で範囲を絞ります。
- [`not-has-for-absence`](/pseudo/has/#rule-not-has-for-absence)：「Xを持たない要素」は `:not(:has(X))` で書き、`:has(:not(X))` は使いません。
